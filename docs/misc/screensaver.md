---
title: Screensaver
---

The BLEShark Nano includes a set of screensavers that kick in after the device has been idle for a while. They reduce OLED burn-in and are satisfying to watch.

### Available Screensavers

- <strong>DVD</strong> - the classic bouncing logo.
- <strong>Cube</strong> - a slowly rotating wireframe cube.
- <strong>Matrix</strong> - cascading characters.
- <strong>Life</strong> - Conway's Game of Life, an evolving cell grid.
- <strong>Pipes</strong> - twisting pipes weaving across the screen.

### How to Configure

<ul className="step-list">
  <li>Open <strong>Config -> Settings -> Display -> Screensaver</strong>.</li>
  <li>Toggle <strong>Enabled</strong> on or off.</li>
  <li>Set <strong>Timeout</strong> to control how long the device stays idle before the screensaver activates. Range is 5 to 300 seconds.</li>
  <li>Set <strong>Style</strong> to pick which screensaver runs, numbered 1 through 5 in the order listed above.</li>
</ul>

:::tip
When a feature that shouldn't be interrupted is running (a mesh command, an active captive portal, a handshake capture), the Nano keeps that screen active and skips the screensaver until the feature finishes.
:::
